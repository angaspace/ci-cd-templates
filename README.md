# ci-cd-templates

Reusable CI/CD pipeline templates for Anga Space clients.

## Status
Work in progress. No templates published yet.

## Planned
1. GitHub Actions workflow: lint and test on pull request
2. Secret scanning step (e.g. gitleaks)
3. Deploy to AWS using OIDC role (no stored access keys)
4. Slack notification on success or failure

Each template will list what it does, required secrets or roles, and the date it was tested.
